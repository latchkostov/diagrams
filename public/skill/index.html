Use Live Diagrams with your AI agent

The livediagrams Agent Skill lets your coding agent draw diagrams for you. Ask "diagram our order pipeline" and it writes a .diagram.json file, checks it, and asks what you want back. Nothing is uploaded. It needs Node.js 20 or later, and no account or API key.

  • Interactive HTML file, recommended for work and company diagrams: one file that plays the simulations, works offline and makes no network requests. Only people who have the file can open it.
  • Diagram file (.diagram.json), to keep editing at livediagrams.dev.
  • Image: it tells you how to export one from the app.
  • Share link: anyone who has the link can open the diagram, so private diagrams never get one.

Claude Code

Run these two commands in Claude Code:

/plugin marketplace add latchkostov/diagrams
/plugin install livediagrams@livediagrams

Claude apps (claude.ai, desktop)

Download livediagrams-skill.zip, then upload it in Settings > Capabilities > Skills.

Codex

Unzip the skill into ~/.agents/skills/ (for you) or .agents/skills/ (for one repository).

macOS, Linux

curl -LO https://www.livediagrams.dev/livediagrams-skill.zip && unzip livediagrams-skill.zip -d ~/.agents/skills/

Windows (PowerShell)

iwr https://www.livediagrams.dev/livediagrams-skill.zip -OutFile livediagrams-skill.zip; Expand-Archive livediagrams-skill.zip "$HOME\.agents\skills"

Other agents

Agents that read the Agent Skills format: copy the livediagrams/ folder from the zip into the agent's skills folder. The skill itself is SKILL.md.

Then ask

"Diagram a Kafka order pipeline: an order service publishes orders.created, billing and inventory consume it, and failed messages go to a dead-letter queue." For a work diagram, ask for the HTML file and a "Confidential" banner.

In the browser

If your browser's AI assistant supports WebMCP, it can change the diagram open at livediagrams.dev directly. Type your request in the assistant, not in the page; each change appears in the page's AI panel with Undo.
