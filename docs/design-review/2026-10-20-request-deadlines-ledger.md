## Request deadline rework UX review

The original feature's Timeout field stays beside While waiting in the connection inspector.
No global controls are added. Empty means no timeout, invalid numeric input retains the saved
value and reports accessible feedback, and the effective-policy editor preserves Undo, saved
simulation overrides, drafts and slow-motion protections. Timeout and discarded-reply counters
remain visible on the connection and caller details.

The public payment lesson retains 120 requests/s, 100 Checkout threads, the provider's tenfold
slowdown at three seconds, the 600 ms comparison and the five-second gateway timeout. It teaches
bounded waiting within ten seconds without changing traffic to manufacture a gateway failure.
The generated metadata packing changes no gallery content or thumbnail geometry.

Rejected broad fail-fast cleanup for calls without deadlines because it changed existing W1
goldens outside this migration's contract. Rejected budget increases and an additional lazy
numeric-feedback component: metadata packing preserves the existing field rendering and all
bundle limits without another UI loading boundary. Pools UI, busy-thread scaling and new Checks
remain outside this PR.
