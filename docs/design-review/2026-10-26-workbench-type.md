## Review

The canvas now uses the same UI face as the frame. Pills keep their words; a crowded route falls back to a hover dot. Active and flagged second lines get room without expanding every background card. Red has one meaning, loss; throughput and processed counts no longer imply failure.

## Decisions

Kept all budgets unchanged. Rejected the larger embedded width-axis face because it exceeds the skill ZIP cap; the app and image exports use it, while Interactive HTML retains its existing Mona Sans weight face. Output colour tokens moved into this parity-recording step so later chrome tuning does not silently rerecord exports.
