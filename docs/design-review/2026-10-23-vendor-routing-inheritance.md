## Consistent vendor behavior

Changing Kong to APISIX, API Management to Apigee, or a generic CDN to its vendor
variant must preserve the authored route table and its inspector section. The
shared capability resolver restores that contract in editing, playback and
capacity analysis. Empty tables keep the same refusal behavior as the parent.

## Chrome and disclosure

No new controls or sections are added. Existing routing and admission controls
remain in their established inspector locations. The regression renders the real
inspector and loaded planning fields for all 58 variants, comparing its test IDs
with the parent with Simulation expanded and authored routing retained.

## Review limits and decisions

This review checks source behavior and static inspector rendering. It does not
claim a new visual, keyboard or screen-reader walkthrough. No layout, focus,
camera, wording or animation behavior changes. Separate vendor-specific routing
controls and duplicated capability tables were rejected: the existing parent
contracts already define the intended behavior. Icon cache changes affect asset
URLs only; each SVG remains individually loaded.
