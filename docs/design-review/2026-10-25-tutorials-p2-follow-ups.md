## Tutorial P2 UX review

The compensation instruction now follows the existing acknowledged-reading pattern: the learner can select and watch the declined checkout, then use the existing Skip step action when ready. Simulation time cannot dismiss the instruction while it is being read. No control or persistent chrome is added.

Retry-budget repair changes only the percentage and supplies a floor only when absent, including preserving an explicit zero. An enabled breaker with custom thresholds completes the same instruction as its default configuration. Narration cannot advance a demo past a refused Continue. Inputs and Simulations remain separate surfaces with independent checks and commands.

The gateway test waits for the application's camera and focus readiness. Assertions and UI timing limits remain intact.
