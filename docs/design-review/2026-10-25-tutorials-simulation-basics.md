## Simulation basics UX review

The lessons use the existing tutorial strip, inspector, Live bar and context menus. No global
controls are added. Each instruction names its control and choice; each done line explains the
result. Readout, traffic, outage and journey moments are sticky, while state checks read the
published session and machines. Source Rate is distinguished from the run's Inputs multiplier.

Capacity recovery is gated on the increased worker fleet, so an empty queue at startup cannot
complete the recovery moment. The slow-motion lesson uses the existing runner's camera guard.
Pending owner choices keep capacity and slow motion out of cards, search and deep links.
Saved simulations remains hidden until its specified scenario can actually pause for Continue.

The Timeline disclosure uses its existing section test ID, which the catalog lint can verify.
No app component, focus policy, layout, chrome or camera behavior changes.

Skip on the authored Drill's Run step preserves a learner's differently named saved run and
ensures a runnable reference with the existing save/run forms. Its regression test reproduces the
stall when only the reference id is run without ensuring it exists.
