## PR 408 round 1: persistent objectives

The lesson objective is the first instruction block in both input modes; the route's current
action follows it. Identical blocks are removed rather than making learners read the same sentence
twice. Generated routes retain the lesson's complete requirements, while their targets provide
the mechanics for the selected input method. Each complete sentence owns its inline shortcut chips.

No controls or chrome were added. The existing phone sheet keeps its compact behavior; regression
checks require its complete rectangle and help controls to stay onscreen through target changes.
The tablet's crowded grow case keeps an eight-pixel clearance inside clear panes, preserving the
existing target-distance limit and obstacle avoidance with the complete objective visible.
The pointer arriving at the card holds it through its click, even when a closing menu reveals a
distant target. Viewport and obstacle guards still apply; release restores the distance limit.
Pointer and Keyboard coverage includes connect, reconnect, API Gateway's independent Users service,
and both grow steps in lesson 1.3.
