## Message types fix-round UX review

The fixes preserve the existing chrome budget. Appended rules remain in the bounded page and reachable through the existing Tab order, even when another rule reuses a historical name. Exact search results precede substring matches in both message readers; overflow counts describe the matching population while the selected count still accounts for hidden selections.

Read-only viewers dismiss transient cards with Escape through the interaction controller. Dialogs and menus keep precedence, and dismissing a card keeps focus on its edge.

Rejected retaining name aliases because editable names can identify a different row after Undo. Rejected increasing rendering caps or adding pagination controls: exact-match ranking makes a specific name reachable within the existing bounded surface. No new controls or translation keys are needed.
