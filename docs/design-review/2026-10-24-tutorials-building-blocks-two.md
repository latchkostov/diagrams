## Building blocks batch two UX review

The five lessons use the existing tutorial strip, coach marks, inspector, Live menu
and simulation picker. They add no controls or toolbar rows. Goals name the exact
control and choice; completion copy states the lesson in one sentence. Scenario
narration remains in the example's note card, and its expectation chips report outcomes.

Public examples open in a sandbox with no automatic save. Node subjects resolve by
stencil; connection targets resolve by endpoints. Typing a setting appends to the
existing list, and the secret demo locks that added entry without replacing other
keys. Focus remains entirely with the interaction controller.

Rejected changing the SMS outage to make messages fail: its existing lesson is queue
isolation while a sender is paused. Also rejected auto-starting the outbox happy path,
which arms tracing before the learner can use the trace control. An explicit happy-path
step preserves the saved scenario while keeping tracing teachable.

The new filter test address makes an existing choice explicit for authoring checks;
its rendered test ID and interaction are unchanged. Tutorial definitions and runtime
extensions remain behind the existing lazy tutorial surfaces.
