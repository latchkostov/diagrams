## Scope and discoverability

The Select submenu holds Extend selection, Remove from selection, Inside this area and Select similar.
The existing Inspector overflow and Ctrl+K expose the same registry actions; the top bar gains nothing.
Boundary actions share their own submenu so the existing twelve-row menu budget remains intact.
Shift extends the established navigation family, with exact modifier matching and menu routes for conflicts.

## Focus and cancellation

Focus follows selection; there is no separate unselected focus target or toggle mode. Removal uses the next
selected item in reading order and the canvas when empty. Announcements include the resulting count.
The interaction controller queues input while the optional language catalog loads, preserving order and
discarding a late batch when the person presses elsewhere, changes focus, blurs, changes mode or replaces
the document. Applying an area retains canvas focus; cancellation restores the opener.

## Area dialog

Searchable native From node and To node pickers use full rendered bounds. Wholly inside starts on, Add
to selection off. The outline and count preview are transient; one primary Select applies and Escape
cancels. Numeric coordinates were rejected because they do not describe a meaningful user decision.
Boundaries and zones retain the pointer selector's containment rules. Selection is not an Undo step.
The visual review moved the dialog beside the preview and removed backdrop blur, so its outline remains
legible. Search and native select controls reuse the existing form styles and focus indicators.

## Lessons and review

Both formerly pointer-only lessons now exercise real product routes without Skip or weaker completion
checks. Their keyboard solutions are the approved demonstration exception; no new showcase is added.
The review covers menu budget, empty-selection reachability, keyboard focus, announcements, cancellation,
mixed selections, exact shortcut modifiers and deferred loading. No simulation engine or WebMCP API change.
