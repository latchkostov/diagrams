The inspector keeps its existing controls, 25-rule paging, and incoming/outgoing message vocabulary.
Internal IDs never appear in labels, pickers, tooltips or message traffic. Renaming keeps the same
mounted row and keyboard controls; Add continues into the new row, Remove into its neighbour,
and Undo/Redo keep every locally appended row visible beyond the current page.

Names and object references were rejected as row identities: names can be reused after Undo,
and room projection copies objects. Rule IDs (derived or explicit) survive both without adding chrome or
expanding the imported page. The existing public diagrams already exercise message renaming;
this identity repair adds no simulation, planning or stencil feature needing a new showcase.
