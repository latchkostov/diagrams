## Building blocks batch 1: UX review

A designer-agent source review checked the five lessons against the UX principles.
The batch adds cards in the existing Tutorials view, with no new toolbar controls.
Quick-add guides narrow the requested stencil; naming uses the existing inspector,
near-miss correction and editor-mode settling. The tutorial never moves focus or reads
the DOM to decide progress.

The cache share goal was shortened to name the two connections and their exact field
values. Incoming-edge keyboard instructions moved to Show me to keep the strip readable.
Lessons state the model's limits: independent message shares stand in for cache hits,
and reducing Replicas stands in for capacity loss rather than a per-instance Fault.
The gateway finish distinguishes distribution from address routing.

Checks require real traffic, both queue workers, and ten new completions after the
replica reduction. Skip performs a sticky milestone's demo before holding that milestone.
Correcting an add-and-name step reuses the existing node and connection.

The generated browser solutions and Skip-all paths provide interaction verification;
the designer review itself was a source review, not a visual browser audit.

Browser verification found the downstream + could sit beneath the inspector edge after
an add. The solutions now use the existing Fit view control before clicking the next +,
and their hints explain it. The camera follow-up is recorded separately; this batch
does not change shared placement or focus policy.
