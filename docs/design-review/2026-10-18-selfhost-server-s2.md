## Self-hosted server S2 UX review

This batch adds server hosting and operational endpoints without adding editor controls or
changing browser workflows. Base-path redirects preserve the query, SPA navigation returns the
application, missing resources remain HTTP errors, and auth pages preserve popup communication.
Operators retain the existing self-host header generator and opt into metrics and IP logging.

The chrome budget is unchanged. Client collaboration mode, connectivity wording and deployment
packaging remain in their approved later steps. No simulation, planning or stencil feature is
introduced, so no showcase example is needed.
