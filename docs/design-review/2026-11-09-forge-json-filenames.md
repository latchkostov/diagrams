## Renamed Confluence uploads

The existing Choose, Replace and drop paths accept `.json` files without extra controls or changes
to the chrome budget. Filename errors explain the next action in one short sentence. Content errors
retain their existing guidance, focus and announcement behavior. Arabic guidance isolates the file
extension and product name. Attachment selection applies the same filename rule before the existing
content, size, page and version checks.

Rejected filename-specific exceptions for browser download counters: accepting `.json` directly is
simpler and also covers manual renames. Kept validation and resource budgets unchanged.
