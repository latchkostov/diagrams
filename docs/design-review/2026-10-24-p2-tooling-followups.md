## UX review

This tooling batch adds no controls, copy, shortcuts, or changes to canvas layout. Existing progressive disclosure and chrome budgets are preserved.

Hot replacement keeps visible output-bearing consumers in export readiness until React replaces them. ZIP compression moves off the development request thread, while viewer and ordinary skill downloads remain available during compression. Source invalidation cannot let an older ZIP overwrite the newer cache.

Rejected suppressing all duplicate registrations: unrelated modules must still report an ownership error. Rejected raising the ZIP cap, changing compression options, reducing property coverage, and weakening test assertions. Serial heavy-project execution removes instrumentation contention without changing simulation behavior.
