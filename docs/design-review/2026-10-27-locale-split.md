## Locale catalogs on demand

The change adds no toolbar controls or navigation steps. Existing lazy surfaces keep their modal frames,
Escape/Close behavior, cursor rules and focus handoff while translations download. The simulation
section uses the existing translated loading and failure copy rather than an empty section.

Core retains shell labels, loading/error/Retry messages and names shown on canvas cards. Optional
surfaces wait for their strings before rendering; language changes publish the shell and previously
used surface catalogs together. Arabic direction changes with that atomic switch and never mirrors
the diagram. Library search retains typed input through a failed catalog and Retry. Editing surfaces
retain their export-skip policy; Live remains output-bearing and waits for readiness.

Rejected: a whole-language download before first render; rendering English while an optional catalog
loads; a separate retry or focus system; larger locale budgets or smaller canvas/Live reserves. Complete
standalone skill-page catalogs and parity output remain part of verification. No new example is needed
because this changes loading behavior without adding a simulation, planning model or stencil feature.
