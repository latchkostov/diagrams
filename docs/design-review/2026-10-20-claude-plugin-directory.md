## Claude plugin directory packaging UX review

The required designer review found no blocking issues. The install page keeps its existing commands
and adds one plain sentence: directory availability is coming soon and depends on approval. There
is no speculative link, new control or editor chrome. The sentence uses the page's translated
message binding and a stable test id.

The plugin README distinguishes installation available today from the pending directory listing,
offers three concrete requests and explains local outputs versus an optional website visit. The
submission pack identifies the owner-only contact, acknowledgement, validation and webhook steps.
It distinguishes update detection from review and publication. A separate editor layout or timing
change was rejected because this work changes packaging and install-page prose only.
