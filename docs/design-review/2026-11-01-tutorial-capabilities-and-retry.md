## Capability and recovery review

No controls or chrome are added. Optional lessons use the product's build capabilities, leaving the core syllabus and its seal available. Unavailable discovery metadata keeps the existing explanation without shipping the lesson's implementation.

Retry returns focus to its original control, or the owning dialog when that control has disappeared. The return happens in the click event, preserving immediate Escape and the dialog's Tab cycle. An action that moves focus into another surface retains that focus.
