## Six restored lessons: UX review

The designer review checked the six authored paths against the October 25 owner decisions and the existing controls. No new chrome or runner state is needed. Capacity keeps the real View menu; slow motion ends at its observable finish; the narrated retry run pauses for Continue; cold start reads starting instances; replay remains an explicit reading rather than an unavailable action.

The initial load-shedding draft exposed three problems: a short empty run could finish while the learner read, editing a saved run's Queue limit changed a simulation override rather than the base property being checked, and the disclosure name did not match the UI. The final lesson keeps its seeded run available for ten minutes, requires the API backlog readout, leaves Live before editing the base queue, names Advanced · queue exactly, then restarts for the bounded comparison. Its injection step counts delivered requests on the incoming connection rather than waiting for the source's successful replies.

The final static designer review found no remaining blockers. Catalog checks, real-controller tests, completion perturbations and generated browser paths verify the corresponding interactions. Assertions and bundle floors remain unchanged.
