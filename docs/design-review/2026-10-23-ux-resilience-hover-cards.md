## Review evidence and rejected alternatives

Production browser checks cover named/associated groups, collapsed tuning, gallery discovery, single-stop event navigation, one hero verdict, Outcomes history, Arabic numeric isolation, and unpinned Escape focus return. The five new browser cases passed three consecutive repetitions. Existing hover-card, retry and timeline assertions change only for the intentional structure/copy/bidi changes. Unit regressions reject the previous failure calculation, loss-only budget conclusion, undiscoverable breaker search, duplicated verdicts, default-only breaker prose, and conflated focus/pin state.

Clamping the percentage was rejected because it conceals a population mismatch. The shared rate uses cumulative settled attempts, explicitly labeled since restart; it does not divide completions by starts or reinterpret current health. Splitting the comparison into several gallery cards, adding toolbar buttons, translating the new copy, changing health rules, fabricating a verified fix, and shortening the lesson were rejected as outside the authorized scope. Bundle limits are preserved; development-only diagnostic formatting is removed from production instead of raising a limit.
