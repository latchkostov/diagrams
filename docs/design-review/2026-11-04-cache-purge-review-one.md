is shown explicitly instead of displaying All rules while retaining an invalid
ID. Its validation error points to the Rule selector; selecting All rules or an
available rule repairs it. Earlier timeline edits determine the actual choices,
with stable array order for simultaneous steps, matching playback validation.

names the cache, hard/soft/deploy action and rule scope. All 37 translated

for bidirectional text. The cache surface installs this copy before accepting
purges, so the announcement does not depend on a subsequent network request.

with DOM and validation regressions. Menu completion is covered for repeated
hard, soft, per-rule, all-rule and deploy actions; rejected actions stay silent.

tracked items retain one-request flights. Soft purge retains missing copies as
misses, keeping the hard-purge lesson honest. No workload, duration, chip
threshold, agreement tolerance or bound was changed to preserve a story.
