## Message picker and example discovery review

No controls or copy are added. Empty pickers preserve authored order and selected/offered population
limits; search retains exact-match ranking, overflow announcements and no-match guidance. Normalization
begins with an actual searchable query and is reused afterwards.

The eager example shell retains its authored summary and open/run identity. Discovery still owns
thumbnails, descriptions and tags behind the existing lazy boundary; its types now enforce that contract.
The gallery requires enriched records and no longer asserts a possibly missing thumbnail into existence.

Visible diagram-scope diagnostics remain quarantined. Active fallback tests require omitted analysis
and a non-clean summary for each gated cycle. Restoring warning rows or changing their identity scheme
belongs to the separate scope-diagnostics follow-up.
