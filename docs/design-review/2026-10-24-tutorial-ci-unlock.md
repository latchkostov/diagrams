## Keyboard and password prompts

The Tutorials link stays in the shortcuts footer with no additional editor chrome. Keyboard traversal
includes every footer link, wraps in both directions, and Escape restores focus to the invoking control.
The regression also verifies the sheet's Tab and Shift+Tab entries.

Navigating while a password link decrypts keeps the current diagram and the original prompt. Its existing
error explains that another diagram opened and offers the same password field for retry. Stabilizing
the shared-link callbacks preserves that behavior without changing imports, storage policy or copy.
