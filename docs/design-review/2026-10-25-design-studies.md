## Design studies UX review

Uses the existing Design studies cards, tutorial strip, Show me, Skip and finish card. No new
controls or chrome. Outcomes come first; hints point toward relevant properties without naming
the reference values. Existing runner data suppresses coach marks until Show me.

Milestones use subjects resolved by stencil, so learner-created nodes count. Reference changes
use editor operations and patches; no focus calls, DOM-derived completion or runner changes.
Seeded runs require elapsed simulation time and actual processing alongside bounded counters,
so an idle zero cannot satisfy a traffic milestone. Finishes invite comparison with public examples.

Dispatch stays out of discovery until the owner decides how the two-run comparison should work.
The outbox and idempotency lesson text states the implementation obligations behind the diagram.
