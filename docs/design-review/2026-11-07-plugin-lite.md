## Directory plugin and layout on open

The directory channel returns an editable diagram file and clearly hands HTML, images and requested
links to the app. Private diagrams stay private, and the skill preserves the full channel's rules for
secrets, personal data and untrusted diagram text. The marketplace recommends the full channel without
changing the directory submission path.

Opening a file without numeric node positions uses the existing layout before displaying it. Existing
positioned files retain their previous parsing, routes and fixed sides. A short info toast explains the
automatic layout, with no added controls or confirmation. The chrome budget is unchanged.

The designer review found that the Lab JSON loader also needed this quiet notice. It now reports layout
only after a successful load, matching file, paste, share and embedded-link paths.
