## Capability-off lesson discovery

The existing Chapter VII rows, Optional extension markers and unavailable screen
explain build limitations in place. No controls or chrome were added. Disabled
rows keep stable numbering, and direct links and palette choices reach the same
explanation with a return to Tutorials. Required lesson counts match seal rules;
optional capabilities cannot block core completion.

## Rejected alternatives

Removing the rows makes the syllabus incomplete and leaves palette choices at an
unknown lesson. Retaining full lessons behind disabled buttons ships unnecessary
prompts and feature code. Lightweight metadata stubs preserve discovery while
allowing the production build to remove those implementations.
