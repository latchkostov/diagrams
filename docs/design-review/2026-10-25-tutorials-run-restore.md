## Tutorial recovery review

The final Author a Drill instruction points to the existing Simulations picker, following the same saved
run path after manual authoring, Skip Save and Continue. Closing the editor first removes dependence on
its local draft or list view. Opening the editor counts as a completed moment, so closing it does not
send the learner back to Open. No new controls or runner behavior are needed.

Restore checks the outage it teaches. An independently applied slowdown or failure stays in place and
does not prevent completion. Regressions cover the menu action and Skip while preserving the slowdown.
