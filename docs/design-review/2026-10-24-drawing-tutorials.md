## Drawing tutorials UX review

A designer-agent source review checked all five lessons against the UX principles. The lessons add no chrome: learners act on nodes, dots, connection menus and the existing property sheet. Naming uses the shared expected-name feedback and waits for naming to finish. Drawing actions that later steps replace retain their completion.

The review identified two issues, both addressed: Insert now explicitly tells the learner to type gateway in its searchable submenu; post-change traffic waits for the rebuilt Live run rather than accepting old counters. A regression covers both publication orders and fails with the stale-counter guard removed.

The Insert solution types its translated search term through the normal submenu. Extending submenu guides would require a shared canvas change and is deferred to preserve this lane and the zero-byte first-view requirement. The tutorial adds no focus moves. Existing app controls already provide all needed test ids.

The first production-browser pass caught an unconditional Inspector wait on an unselected seed and Skip treating sticky edits as empty moments. The gesture helper now waits for the Inspector only when selection exists; Skip performs available demos independently of sticky completion, with a failing-before-fix regression and representative machine paths. Browser playback also caught edge-group bounds missing a bent path and the existing Relationship action being edit-only; the helper now hits the rendered path, and the same contextual action is available in Live. This adds one relevant menu row and no top-bar control. The generated production-browser solution and Skip-all cases verify the corrected paths.
