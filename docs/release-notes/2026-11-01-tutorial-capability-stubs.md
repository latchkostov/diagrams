## Optional lessons in capability-off builds

Chapter VII keeps the Work together and Review agent changes rows when their build
capabilities are disabled. These lightweight entries show the existing unavailable
explanation and Optional extension marker, with disabled lesson buttons. Direct
links and command-palette choices open the explanation without a Start action.

Runnable lessons retain their full content only when enabled. Stubs contain no
steps, fixtures, copied prompts, AI implementation or collaboration implementation.
Optional extensions remain outside chapter and core seals. Chapter footer totals
describe the required lessons, matching the seal counts.

No parity goldens changed.
