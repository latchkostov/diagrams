## Message choices follow playback

Message choices, Carries, hover details, agent descriptions and Checks now share playback's forwarding decisions with capacity analysis. Async store change feeds carry their real output types, broker consumers ignore fan-out shares, and request tables and filters select the same routes. Saved simulations contribute their own traffic types and setup overrides without combining unrelated run configurations.

## Verified loop fixes

Filter and rename candidates are checked against the whole graph's cyclic typed transitions. A rename that merges existing loops into a new loop is rejected. Verification preserves non-loop traffic in free play and each saved simulation, including its setup overrides. Runtime property edits require temporal proof and therefore receive no automatic fix from this static verifier.

All loop findings share indexes, cached candidate analyses, a 24-candidate limit and one work/allocation budget. Findings remain visible when optional fix verification runs out of budget. Applying a fix regenerates only that finding's candidates, while checking safety across the whole graph. Traversal keys intern type names, and routing-content cache keys bound serialized names without truncation collisions. Moving or selecting diagram elements reuses the same propagation result; leaving an edge suspends its reader.

## Keyboard editing

Removing a processor rule, including choosing Unchanged, sends focus through the canvas focus controller to a surviving rule or Add a rule. Rules keep their incoming-type identity, so a removed row's draft cannot move to another rule. New-type inputs focus when mounted, without stealing focus during unrelated edits. Keyboard-focused flow edges show a readable tooltip associated with their wrapper through aria-describedby.
