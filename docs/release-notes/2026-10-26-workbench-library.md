## Workbench tools and library (step 2)

The tool rail keeps Select, Add, Annotate, Checks, Stencils, Shortcuts and AI together.
Tutorials appears there in builds that offer it. Add opens the searchable stencil
library over the canvas; Pin open remembers the docked column. Common stencils lead
the list. Escape closes a flyout and returns to its opener; outside clicks and drops
close it without taking focus.

## Compatibility

Stencil, search, family, category and annotation control ids stay on their controls.
The Checks count, view navigation, shortcuts and AI opener move to the tool rail.
Tests open Add or Annotate before using a moved surface. Exact warning assertions
read the warning text within the rail item; no-warning assertions check its badge.
The mobile-app, API-gateway and annotation lessons follow those opening actions.
New chrome and changed library instructions are translated in all 37 locales.
