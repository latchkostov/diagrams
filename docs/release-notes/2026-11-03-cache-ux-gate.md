## Caching is easier to find, configure and explain

Searching examples for **cache** or **edge cache** finds Black Friday. Its summary now explains how the edge answers repeat product requests and reduces requests reaching the services behind it.

Empty node descriptions start with **Add description…**. Route table and Cache rules have independent, summarized disclosures. Adding rules opens the relevant section. Within a cache rule, the name and match summary lead to Keep for, Items, Popularity and Expected; **Edit match** and **Rule actions** hold less frequent controls. Keyboard reorder, deletion, focus return and Undo remain available.

Caching readouts use **Answered here (hits)** and **Requests kept away from {node}**, with hit ratio and origin offload as secondary terms. This vocabulary change is scoped to caching. The compact hover header remains compatible with the separate Expected/Live agreement work. Expanded details show counts, distinguish **No requests yet** from measured zero, and describe Don't store as **Not cached: all {rate} reach {node}**.

Cache latency says **At this cache since restart**, explains the 95th percentile once, uses milliseconds below one second, and labels actual zero hit latency **0 ms modelled lookup**. Large-diagram cache explanations offer Live measurement instead of asking to simplify the diagram; bounded analysis remains a separate queued follow-up.

**Simulation ▸ Add routes… / Add cache rules…** and the **Copy** family keep all 13 caching-capable stencil menus at 12 top-level actions. Enabling caching explains which services will receive fewer requests, focuses the updated model summary and offers **Enabled caching · Undo**. Legacy export distinguishes the older downloaded file's consequences from the current diagram, with field paths and model identifiers in Technical details.

Arabic caching controls and explanations are translated together. Rates, percentages, paths, durations and names are isolated for mixed-direction reading; native controls retain their keyboard behavior.
