## Keyboard recipe field navigation

Keyboard tutorial recipes now take the direct route between fields in the current Inspector.
The former shortest cyclic route could wrap through the canvas, where focusing another node
changes selection and replaces the fields. The macOS load-shedding trace reaches Client's
Simulation fields while its next action expects API's queue settings.

Two controlled browser regressions cover traversal in both directions. Each fails when the
route correction is temporarily reverted and passes after restoration. The application's Tab
order and selection behavior are unchanged. No output golden is re-recorded.
