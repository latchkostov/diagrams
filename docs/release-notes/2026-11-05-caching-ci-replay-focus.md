## Caching tutorial replay and command search recovery

Cache lesson checks and saved-run repairs reuse compiled request addresses and rule predicates across
Live publishes. Content stamps invalidate them when a learner changes the matching fields, including
in-place edits. This removes repeated compilation introduced by the first-serving-rule repair, without
changing which rule is repaired or the replay's outcome requirements. The CI coverage failures reached
the completion sweep's existing backstop; passing sibling cases also finished near that backstop.

Command search retains captured typing until its input actually receives focus. If an outgoing modal
temporarily prevents focus, the palette retries on the next frame. Typing `diagram properties` and
Enter during that handoff therefore opens Properties instead of running the idle Go live command.

Operation-count and blocked-focus regressions fail with their respective fixes removed. Completion
checks, test assertions, playback durations and backstops remain unchanged. No parity golden changes
are intended or recorded.
