## Tutorial assistance respects Live views and Undo

Skipping a read-only view step, including Events in Read a node, now opens the view while slow motion is active. Engine-changing demonstrations still enter recovery when slow motion blocks them.

After a failed demonstration, Retry returns to any prerequisite reopened by Undo so the learner can complete or Skip it before retrying the later action. Learner edits remain intact.

No output goldens change.
