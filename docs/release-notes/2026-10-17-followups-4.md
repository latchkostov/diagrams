## Follow-ups 4: Inspector, export and Lab recovery (2026-10-17)

- Opening, closing and resizing the Inspector refits fitted editing and Live views. Manual zoom/pan ownership,
  narration focus and paused slow-motion views survive pane changes; playing fitted replays replan their camera
  without restarting playback.
- Route headings have space, Last wraps by word, and narrow target lists again say “Pricing +1”. Full lists
  remain in titles and accessible row names, and return when the sheet has room.
- Manual sheet widths stop at 960 px, including old saved preferences. Form fields stop at 640 px while tables
  can use the available width. The default width, narrow layouts, resize gestures and persistence model stay intact.
- Inspector wording and accessible names use the translation catalog. Resize instructions and spoken widths,
  plus “Exporting PNG…” wording, have all 37 locale translations. Shared existing translations are reused for
  identical Inspector messages; Arabic field labels are included. Remaining messages use documented English fallback.
- Image export has one progress indicator and gives preparation visible progress before cloning. Cancel, Escape
  and focus return keep working.
- Lab rooms show a bounded connection failure with Retry and file fallback while preserving edits. Invalid links
  offer an explicit new room. Device-storage failure replaces the ordinary status with one spaced message and a
  file-copy action.
- Agent layout preserves each boxed note's coordinates when validation repairs duplicate annotation IDs, including
  when malformed annotations are skipped. Optional collection result types now reflect preserved unknown inputs.

The regression batch also pins the large-candidate obstacle budget, cancellation during resource conversion,
decode progress, and a durable final save when leaving during retry backoff. Existing implementations that already
meet those contracts are retained.
