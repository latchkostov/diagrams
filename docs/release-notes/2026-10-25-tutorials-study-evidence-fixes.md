## Tutorial study evidence corrections

The cells study identifies each boundary by its service membership, so either cell can be created first.
An unrelated boundary no longer claims a cell's subject. Isolation metrics keep using the resolved cells.
The runner is unchanged; existing lessons retain their order-based selectors. A fixture exercises membership
sets through catalog validation, both creation orders and the completion sweep's perturbations.

The RAG study now describes Share as independent sampling of each outgoing Request. A question can reach any
combination of cache, search and model, including none. The measured p95 belongs to this sampled workload;
it does not establish correlated cache hit/miss latency or answer quality.

Provider regressions isolate each provider's rejection guard. Cell containment regressions independently require
deployed-cell failures, zero neighbouring failures and completed neighbouring traffic after five simulated seconds.
Removing any one guard makes its regression fail.

The only changed golden is `tests/parity/goldens/node/i18n/catalogs.json`: all 38 tutorial-area digests change
because seven RAG messages now use keys and wording that describe independent sampling. Message and fallback
counts, all other areas, and the other two i18n goldens remain unchanged.
