## Design studies return with draft-aware Skip

Checkout, Payments, Dispatch, Fan-out and RAG are available again from tutorial cards, search, suggestions and
direct links.

Skip and Continue now repair a milestone wherever the learner changed it: the diagram, a saved run's Inputs and
connection settings, and an unsaved run the learner started from Simulations. An unsaved run stays unsaved, with
its title, traffic and timeline kept. Only the settings the milestone needs change; everything else the learner
set stays theirs. A design study's Skip replays its run as designed, with saved Capacity and Traffic multipliers back at ×1. If the Simulations panel is open on that run, its copy gets the same repair, so pressing Run or Save there keeps it. RAG raises answer deadlines that are
shorter than the two-second budget. Fan-out recognizes a channel's queue while either of its connections remains.

Saving Inputs and saving or running simulations work exactly as before. An earlier, unreleased version of this
change could drop unsaved Simulations edits when Inputs were saved; that can no longer happen.
