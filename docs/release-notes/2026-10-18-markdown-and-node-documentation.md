## Markdown rendering, editor shortcuts, and node documentation

Diagram descriptions, text annotations, sticky notes, and a new per-node `description` field now render and edit GitHub-flavored Markdown.

- **Zero-dependency CSP-safe Markdown engine (`src/components/markdown/`)**: Parses and renders headings (`h1`–`h6`), bold, italic, strikethrough, inline code, fenced code blocks, blockquotes, unordered/ordered/task lists, pipe tables with column alignment, horizontal rules, and URL-validated links (`http:`, `https:`, `mailto:`, `#`, `/`) into pure React elements without `dangerouslySetInnerHTML`.
- **Preview-first Inspector `MarkdownEditor`**: Displays rendered Markdown in `Preview` mode when populated and opens directly in `Edit` mode when empty, with a 9-row default viewport (`176px`–`380px`), unified border styling across both modes, and `Preview` / `Edit` header tabs.
- **Formatting keyboard shortcuts (`markdownKeys.ts`)**: Both inline canvas annotation editing and the Inspector `MarkdownEditor` support `Ctrl/Cmd+B` (bold), `Ctrl/Cmd+I` (italic), `Ctrl/Cmd+K` (link with automatic URL detection), `Ctrl/Cmd+E` (inline code), `Ctrl/Cmd+Shift+X` (strikethrough), smart list/task/numbered/blockquote continuation on `Enter`, and `Tab` / `Shift+Tab` 2-space indentation.
- **Node documentation (`DiagramNode.description`), corner badge, and tooltip preview**: Added optional `description` to `DiagramNode` across the TypeScript model, JSON schemas (`v1`/`v2`), canvas flow conversion, Yjs collaboration schema, draw.io round-trip (`dg_description`), and the Inspector `NodePanel`. Documented nodes display a subtle top-right note badge (`doc-badge-<id>`) that opens the Inspector on click and render a compact Markdown preview inside the node hover/focus tooltip (`node-tooltip-doc`). Enriched the featured `kafka-order-pipeline` example with Markdown in its diagram description and architectural runbook documentation on all 15 nodes.
