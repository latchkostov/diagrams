## Tutorial Run and Restore recovery

Author a Drill now asks you to close the simulation editor and select the saved Drill through the
Simulations picker. Running works after Skip saves the Drill and after Continue reconstructs the Run step.
Try a Fault now completes Restore when the outage ends, preserving any additional slowdown or failure.

The i18n catalogs parity golden changes only the tutorials area's pseudo-locale (en-XA) hash for the
revised Run instruction and completion message. No other output changes are intended.
