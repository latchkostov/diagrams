## Confluence Data Center recipe

Administrators can install a user macro backed by their self-hosted Live Diagrams viewer. It accepts
a same-origin attachment URL or inline Diagram file JSON, a height and an optional Play diagram button.
Every diagram starts still; the page supplies its data without creating a public diagram URL.

The recipe includes deployment, SSO and CSP instructions and production-browser host-page coverage.
No editor controls or embed-destination step are added. No output goldens change.
