## Deterministic embedded autoplay coverage

The host-supplied embed test uses a connected opening narration path in its own diagram fixture. Its inherited opening focus named two unconnected nodes, so a settled embed below 60% zoom intentionally hid every connection's particles. Fast runs could observe dots before the fit; native Windows and macOS runs then failed after it.

The test waits for the initial camera fit, pauses its installed clock and advances playback explicitly. Slow setup can no longer finish the simulation before the pause command is tested. It still requires visible particles, an advancing clock, host commands, events, CSP and zero unintended requests. No public example, application behavior, assertion, timeout or output golden changes.
