## Annotation shapes in command search

Browsing Ctrl+K (empty search or `>`) now offers one **Add shape…** action, opening the existing searchable shape picker at the canvas centre. Individual outlines remain available by name or alias, including `hexagon` and `> hexagon`. This keeps core actions such as Fit view within the palette's result limit, including after using a shape recently.

Only `node/i18n/catalogs.json` changes intentionally: the new English `shape.addShape` message updates catalog counts and hashes, with English fallback in other languages. No diagram, simulation, layout or export golden changes.
