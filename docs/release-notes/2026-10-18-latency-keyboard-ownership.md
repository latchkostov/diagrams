## Latency details keep their reading keys

Scrollable latency details in editable Live view now own arrows, PageUp/PageDown, Home/End and Space, so reading a breakdown cannot nudge the selected node or toggle playback. Tab enters the details, Shift+Tab returns to their node, and forward Tab continues to the next node in reading order.

Equivalent repeated fault steps now share one work-budget charge regardless of property order. The production lazy-panel handoff test skips development runs and verifies interception before checking loading focus. No output goldens change.
