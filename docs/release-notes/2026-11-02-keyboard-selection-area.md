## Select a subset or an area from the keyboard

Select menus, Ctrl+K and the Inspector's Selection actions now offer Extend selection, Remove from selection
and Inside this area. Add Shift to Ctrl+Alt+arrows or brackets to extend the existing navigation selection.
Unshifted navigation retains its meaning. Removal focuses the next selected item, or the empty canvas.

The area dialog previews the full bounds between two searchable node anchors, with Wholly inside and Add
to selection options. Select applies; Escape cancels. Selection changes do not create Undo steps.

The boundaries and arrange lessons now have real keyboard solutions with unchanged completion checks.
They demonstrate this feature instead of a new showcase example, as approved in the design review.

## Output parity

Only node/i18n/catalogs.json changes: sixteen new selection messages in all 37 locales and two boundary
announcement messages move from the core menu catalog into the optional selection catalog. Counts and
catalog fingerprints change accordingly. Diagram, export, simulation, planning and browser outputs are unchanged.
