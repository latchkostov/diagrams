## Hosts and requests (shared Live P3) follow-ups

P3 resolves four of Watch together's follow-ups (`2026-10-19-watch-together-followups.md`): the inert live bar, the
narration camera rule, a host already in Live, and the version wording.

- **Co-hosts' menu.** Co-hosts answer requests, but the people menu (co-host, drive, host) is the host's alone, and
  the roster lives in the host's presence: with the host away, only a co-host's yes to a request moves the run.
  Design §1 lets co-hosts do everything but change the host's role; that needs the roster outside one person's
  presence (P4's roster log).
- **A handoff to someone not level with the run.** The next driver waits ten seconds to come level with the handoff,
  then starts a run of its own; followers then rebuild. A slow machine far behind sees that more often.
- **"Already in Live" restarts the run.** Starting over at the same moment drops the run's one-off tweaks (an
  injection, a manual fault). A sendable checkpoint (P7) would share the run as it is.
- **Requests from people not following.** Ask to drive is offered only while following; someone not following asks
  to show their own Live instead.
