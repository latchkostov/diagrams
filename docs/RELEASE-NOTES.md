# Release notes

New entries live in [release-notes/](release-notes/), one `YYYY-MM-DD-short-slug.md` file per PR,
using the existing `## Heading` section format. Run `pnpm notes release` for the complete
newest-first view; do not commit that output. Same-day entries sort by filename descending.

The [history through 2026-10-16](RELEASE-NOTES-HISTORY.md) is frozen and remains readable here.
